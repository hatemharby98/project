## 📝 Project Summary  
This project demonstrates the concept of an **Intrusion Prevention System (IPS)**.  
An IPS is a security solution that continuously monitors network traffic,  
detects intrusion attempts or malicious activities, and actively prevents them in real time.

✨ Academic project for practicing and understanding network security concepts.
